# Personal blog project

This repository contains the source code for a personal blog built with Astro. It features a clean, responsive design and supports light and dark themes based on user preferences. The blog is optimized for performance and accessibility, ensuring a great reading experience across devices.

## Technical stack

- **Framework**: [Astro](https://astro.build/)

## UI and editorial voice

When translating UI copy or blog posts, use published blog posts as the primary reference for tone of voice. Preserve the author's personality, rhythm, wordplay, and intentional unusual wording instead of normalizing them or translating mechanically. Reproduce recurring patterns rather than isolated jokes. Keep UI copy concise and accessibility labels direct and unambiguous.
